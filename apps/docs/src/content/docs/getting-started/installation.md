---
title: Installation
description: Install Minions Sequences packages
---

## TypeScript / Node.js

```bash
npm install @minions-sequences/sdk minions-sdk
```

## Python

```bash
pip install minions-sequences
```

## CLI

```bash
npm install -g @minions-sequences/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
