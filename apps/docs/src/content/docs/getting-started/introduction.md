# Minions Sequences

Multi-step email drip campaigns, cadence rules, A/B variants, and open/reply tracking

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-sequences/sdk`) — Core library for Node.js
- **Python SDK** (`minions-sequences`) — Python bindings
- **CLI Tool** (`@minions-sequences/cli`) — Command-line interface
- **Web App** — Interactive playground at [sequences.minions.wtf](https://sequences.minions.wtf)
