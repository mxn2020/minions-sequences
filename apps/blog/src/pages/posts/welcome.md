# Welcome to Minions Sequences

We're excited to introduce **Minions Sequences** — Multi-step email drip campaigns, cadence rules, A/B variants, and open/reply tracking.

## What's Included

- **TypeScript SDK**: `npm install @minions-sequences/sdk`
- **Python SDK**: `pip install minions-sequences`
- **CLI**: `npm install -g @minions-sequences/cli`

## Getting Started

Check out the [documentation](https://sequences.minions.help) for a full guide.
